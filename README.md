# آلة حاسبة بلغة C++

مشروع آلة حاسبة بسيط مكتوب بلغة C++، يهدف إلى التدريب على البرمجة كائنية التوجه (OOP).

## المميزات

* الجمع
* الطرح
* الضرب
* القسمة
* إلغاء العملية الأخيرة
* عرض النتيجة الحالية

## المفاهيم التي تم التدريب عليها

* الأصناف والكائنات (Classes and Objects)
* التغليف (Encapsulation)
* الأعضاء الخاصة والعامة (Private and Public Members)
* الدوال التابعة للصنف (Member Functions)
* التحقق الأساسي من صحة البيانات (Basic Data Validation)

## الملفات

* `main.cpp` — يحتوي على صنف الآلة الحاسبة وتنفيذ البرنامج.
* `readme.cpp` — يحتوي على كود إضافي للتدريب على لغة C++.

## مثال

يقوم البرنامج بتنفيذ عدة عمليات حسابية وعرض النتيجة بعد كل عملية.
